# Radar NEXO

Instrumento de diagnóstico de entrada (Fase I) y de salida (Fase IV) del Programa NEXO — Cámara de Comercio de Bucaramanga. Scala Industries Group S.A.S.

| Carpeta / archivo | Qué es |
|---|---|
| `index.html` | Vista previa **pública** (sin ingreso, no guarda). Es la que enlaza la propuesta: https://scalaig.github.io/radar-nexo/ |
| `app/` | Aplicación **para el equipo** (ingreso, base de datos común, análisis con IA): https://scalaig.github.io/radar-nexo/app/ |
| `supabase/` | Esquema de la base de datos (`schema.sql`), función de IA (`functions/analizar`) y configuración |
| `scripts/` | `instalar.sh` (puesta en marcha), `crear_usuario.sh` (alta de consultores), `respaldar.sh` (copia de seguridad) |
| `docs/` | Guía de puesta en marcha, manual del consultor y modelo de aviso de datos personales |

Empieza por `docs/GUIA_PUESTA_EN_MARCHA.md`.
